02 색 토큰 · Semantic color dark = canonical
{{ g.label }}
{{ t.name }} {{ t.dark }} L {{ t.light }}
faint(#5f646a)는 비활성 컨트롤 전용입니다. 의미를 가진 텍스트 — 플레이스홀더, 조건 라벨, 주석 — 에는 절대 쓰지 않고 muted(#83888f, 5.37:1)를 씁니다. 액센트는 상태 표시에만 씁니다 — 선택, 포커스, 기본 동작. 장식용 액센트 면적은 금지. 상태는 색만으로 전달하지 않고 항상 텍스트를 동반합니다.
